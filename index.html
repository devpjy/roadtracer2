1. 실제 도로 주행 시 HTTPS 필수
스마트폰 브라우저 보안 정책상 file://이나 일반 http://에서는 GPS와 가속도계(진동 센서)가 차단됩니다.
이 단일 HTML 파일을 GitHub Pages, Netlify Drop, Cloudflare Pages 등에 올려 https:// 주소로 열어 사용하세요.
2. 안드로이드 (Chrome) 홈 화면 설치
Chrome으로 https:// 주소 접속 → 우측 상단 메뉴(⋮) → 홈 화면에 추가 (또는 앱 설치) → 전체화면 앱처럼 실행
3. 아이폰 (Safari) 홈 화면 설치
Safari로 https:// 주소 접속 → 하단 공유 버튼(□↑) → 홈 화면에 추가 → 실행 후 상단 센서 권한 일괄 점검을 1회 눌러 가속도계 권한을 허용하세요.
